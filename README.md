# 🚀 Space Battle — Игровой сервер (движение объектов)

[![License](https://img.shields.io/badge/License-MIT-green.svg)](https://opensource.org/licenses/MIT)

Проект реализует логику движения объектов в игровом поле.  
Проект построен согласно **SOLID-принципам**, с фокусом на расширяемость, тестируемость и понятную архитектуру для будущего роста и новых игровых механик.


## 📌 Описание
В звездной системе сошлись две флотилии космических кораблей.  

Каждый корабль:
- Имеет позицию в двумерном пространстве
- Обладает мгновенной скоростью
- Может двигаться в пространстве со своей скоростью

`Use case` движения объектов выделен в отдельный модуль и работает с **абстракциями**, а не с конкретными классами.


## 🎯 Цели проекта
- Демонстрация применения **SOLID-принципов** при проектировании игрового домена.
- Обеспечение расширяемой архитектуры движения объектов.
- Устойчивость к появлению новых типов объектов *(корабли, астероиды, торпеды и т. д)*.
- Поддержка `PyTest` для автоматической проверки корректности логики.


## 🧠 Архитектурные решения
- **Абстракции (протоколы/контракты)** вместо конкретных классов
- **Инверсию зависимостей** для отделения логики от конкретной реализации объектов
- **Fail-fast** — ошибки чтения/записи состояния объекта приводят к контролируемому исключению
- **Value Objects** (например, `Vector`), чтобы выразить данные в виде неизменяемых сущностей


## 💡 Расширяемость
Благодаря архитектуре проекта можно легко добавить:
- Ограничение границ игрового поля,
- Новые сущности (астероиды, ракеты),
- Дополнительную физику движения,
- Асинхронный сервер/сетевую синхронизацию.


## 🧪 Тестовые сценарии
Проект покрывает следующие кейсы:
1. Корректность перемещения объектов
1. Обработку ошибок при невозможности получить позицию/скорость
1. Обработку ошибки при невозможности установить новую позицию
